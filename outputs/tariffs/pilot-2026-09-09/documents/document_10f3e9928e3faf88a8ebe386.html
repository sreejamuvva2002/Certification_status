HS Code for Nickel Sulfate: 2025 Guide

TL;DR: The HS code for nickel sulfate is 2833.24 in Chapter 28; 2025 updates include GCC 12-digit codes and US HTS rules for smooth tariff compliance in global shipping.

The HS code for nickel sulfate remains 2833.24 in the 2025 HS codes guide, vital for importers and exporters facing regional tariff changes. This essential inorganic chemical supports EV batteries and electroplating, but accurate classification prevents costly delays and penalties.

What is Nickel Sulfate?

Nickel sulfate (NiSO4) is a versatile chemical compound used across industries.

  • Chemical formula: NiSO4·6H2O (hexahydrate)
  • Appearance: Emerald-green crystals
  • Solubility: Highly soluble in water
  • Production: From nickel metal and sulfuric acid

In the HS code for nickel sulfate context, precise identification ensures tariff compliance 2025.

HS Code for Nickel Sulfate: Full Breakdown

The primary HS code for nickel sulfate is 2833.24 under Chapter 28 for inorganic chemicals.

HS LevelCodeDescription
Chapter28Inorganic chemicals; organic/inorganic compounds
Heading2833Sulfates; alums; peroxosulfates
Subheading2833.24Nickel sulfate
  • 6-digit global standard by WCO
  • Extended to 8-12 digits regionally
  • Key for customs declarations worldwide

Shipping Nickel Sulfate: Hazardous Rules

Hazardous classification applies to nickel sulfate shipments under HS 2833.24.

  • UN Number: 3288 (Toxic substance)
  • Class: 6.1 (Inhalation/ingestion hazard)
  • Packaging: UN-approved boxes/bags
  • Labels: IATA/IMDG toxic pictograms
  • Documentation: SDS + HS code

Temp control recommended for hydrated forms in 2025 shipments.
