     Provenance model (the crux)

     Flattening 25 fields × 3 provenance attributes into 75 columns is
     unreadable. Instead:

     - Per-record JSONL stores {field: {value, evidence_level, quote, 
     source_url}}.
     - The flat 25-column table carries the value; a companion long-format
     literature_evidence.csv
     (doi, field, value, evidence_level, quote, source_url) carries the proof
     for every cell.
     - evidence_level ∈ {full_text_verified, abstract_verified, metadata, 
     not_stated, not_accessible}.
     - Extraction prompts mandate null-if-not-stated; ground.py then
     independently re-checks each non-null
     value against the source text. A value the model produced but the text
     doesn't contain never ships.
